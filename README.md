# ระบบ POS ร้านอาหาร

Webapp ขายหน้าร้าน: Node.js + Express + SQLite (ในตัว Node) — ไม่ต้องติดตั้งฐานข้อมูลแยก

## เริ่มใช้งาน

ต้องใช้ Node.js 22.13 ขึ้นไป

```bash
npm install
npm start
```

เปิด http://localhost:3000

บัญชีเริ่มต้น (สร้างอัตโนมัติครั้งแรก — **เปลี่ยนรหัสผ่านทันที**):

| ผู้ใช้ | รหัสผ่าน | สิทธิ์ |
|---|---|---|
| admin | admin123 | Admin |
| staff | staff123 | Staff |

ข้อมูลทั้งหมดเก็บที่โฟลเดอร์ `data/` (สำรองทั้งโฟลเดอร์)

## ใช้บน iPad

1. รันเซิร์ฟเวอร์บน Mac/PC ในร้าน — หน้าจอจะแสดงที่อยู่ เช่น `เปิดจาก iPad (Wi-Fi เดียวกัน): http://192.168.1.12:3000`
2. ให้ iPad ต่อ Wi-Fi เดียวกัน แล้วเปิดที่อยู่นั้นใน Safari
3. กดปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอน POS เปิดเต็มจอเหมือนแอป
4. พิมพ์ใบเสร็จผ่าน AirPrint ได้จากปุ่ม "พิมพ์ใบเสร็จ"

เคล็ดลับ: ตั้ง IP ของเครื่องเซิร์ฟเวอร์ให้คงที่ (DHCP reservation ในเราเตอร์) ไม่งั้นที่อยู่อาจเปลี่ยนเมื่อรีสตาร์ทเราเตอร์ และตั้งเครื่องเซิร์ฟเวอร์ไม่ให้หลับ

## ฟีเจอร์

**Staff**
- กดรายการอาหารตามหมวด / ค้นหา, ปรับจำนวน, ใส่หมายเหตุ (เช่น ไม่เผ็ด)
- เลือก ทานที่ร้าน (ใส่เลขโต๊ะ) / กลับบ้าน
- ส่วนลด, คำนวณยอดอัตโนมัติ
- ชำระเงินสด (ปุ่มเงินด่วน + คำนวณเงินทอน) หรือสแกน QR
- พิมพ์ใบเสร็จ, ดูบิลวันนี้

**Admin** (ทำได้ทุกอย่างของ Staff และ)
- เพิ่ม/แก้/ลบเมนู, ปรับราคาในตาราง (พิมพ์แล้วกด Enter), เปิด/ปิดขาย
- เพิ่ม/ลบ บัญชีผู้ใช้, รีเซ็ตรหัสผ่าน
- เพิ่ม/ลบ บัญชีรับเงิน QR
  - **เลข PromptPay** → ระบบสร้าง QR พร้อมยอดเงินให้ทุกบิล
  - **อัปโหลดรูป QR** ของร้าน (ลูกค้ากรอกยอดเอง)
- ยกเลิกบิล (ไม่นับในยอดขาย)
- สรุปยอดขาย รายวัน / รายเดือน: ยอดรวม, เงินสด vs QR, ทานที่ร้าน vs กลับบ้าน, เมนูขายดี, รายชั่วโมง/รายวัน

## ตั้งค่า

- `PORT` — พอร์ต (ค่าเริ่มต้น 3000)
- `TZ` — เขตเวลา (ค่าเริ่มต้น Asia/Bangkok)

> ถ้าเปิดให้เครื่องอื่นใช้งานผ่านอินเทอร์เน็ต ควรวางหลัง HTTPS (เช่น Nginx/Cloudflare)
